Claude 订阅号池：现在的运行原理

客户 → 分组 → 账号集合 → 运输选择 → 调度/槽位 → Claude Code 进程或 Go 网关。分组不再按功能帽子区分，只决定“这个客户能用哪些账号”。

2 一次 /v1/messages 请求怎么走

鉴权与客户/分组

API Key 找到客户与分组；分组给出可用账号集合，不再判断“是不是 CC 分组”。

解析请求

模型、system、messages、tools、image、max_tokens。CC 路径目前不接受 temperature，max_tokens 接受但忽略。

候选账号

按分组账号集合、平台、模型、状态、限额、5h 窗口、RPM、健康度过滤；会话粘性优先。

原子预占槽位

CC 账号用 TryAcquire 预占账号槽 + 全局槽；满了先试其它账号，仍有界排队。API Key 账号走 Redis 账号槽。

确定运输

账号类型决定运输：OAuth/SetupToken → CC；API Key/Bedrock → Go。一次请求不会跨运输 fallback。

CC 路径

Build turn → 选择/恢复 session → 拿 MCP token → 启动或复用进程 → 写 stream-json → 读事件 → 转 SSE。

计费 / 记录

按客户输入 + 上游 output 归一化 usage；CC 注入前缀不计客户费；记录账号、模型、渠道、session。

3 持久 run 与工具调用

请求 A
普通文本 / 图片

RunManager 启动 CC 进程，发送首轮 user turn，流式返回。

工具阶段
CC 决定调用客户端工具

MCP helper 回调网关；RunManager 发 tool_use SSE，结束当前 HTTP 响应，但进程、账号槽、run lease 保持。

请求 B
客户端回填 tool_result

同一个 session 命中同一个 run；Resolve pending，ContinueSession 继续读 CC，最终 result 返回并计费。

idle / 超时
3min idle 或 15min 总寿命

关闭进程，保存 sessionID；下一次请求用 --resume 恢复。工具等待默认 5min，超时释放 run。

工具桥需要：cc_persistent_runs_enabled=true + cc_callback_base_url；否则只有纯文本/图片路径。

5 分组现在是什么

客户导向

客户 → API Key → 分组 → 账号集合

分组不再表达“CC 分组 / 非 CC / 降级分组 / 功能帽子”。它只回答：这个客户能用哪些账号，以及限额、RPM/并发、模型路由。

已删除：claude_code_onlyfallback_group_idinvalid-request fallbackrequire_oauth_onlyrequire_privacy_setmixed type weightssystem prompt policy

保留为运营配置：限额RPM / 并发模型路由内容审计OpenAI messages dispatch

账号集合操作

GET /api/v1/admin/groups/:id/accounts

PUT /api/v1/admin/groups/:id/accounts

请求：{"account_ids":[1,2,3]}

管理端“分组 → 账号”弹窗支持搜索、分页、勾选、保存。

写入使用 ReplaceGroupAccounts 事务，并写 scheduler outbox 刷新调度快照。

6 生产开关与边界

cc_transport_enabled
CC 总开关。关闭时 OAuth /v1/messages 返回 503，不回退旧 Go 伪装。
cc_persistent_runs_enabled
同一 session 复用 CC 进程；关闭时一请求一进程。
cc_callback_base_url
MCP helper 回调地址；不带 tools 的请求不依赖它。
cc_tool_wait_seconds
等待客户端 tool_result 的超时，默认 300s。
cc_max_concurrent / cc_per_account_concurrent
全局 / 单账号并发。一个并发槽 = 一个活跃 run。
cc_run_timeout_seconds
一次性 CC 请求超时，默认 90s。
Redis lease
cc_run_lease:{session}；10min TTL、3min 心跳、非 owner 409。
2h 粘性
cc_sticky_first:{group}:{session}；到期清理 sticky binding，重新选号。
